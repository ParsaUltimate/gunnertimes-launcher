# Gunnertimes Launcher

Gunnertimes is distributed to other players. Resolve paths from each player's environment and use reusable examples in the UI, Help, documentation, and screenshots. Keep maintainer usernames and private filesystem paths out of shipped artifacts.

For Windows Setup changes, test the installer as a player would. Verify a successful install opens the installed launcher and that an upgrade keeps player preferences and profile data. Check the quiet path separately because launcher self-updates use it.

Use the player's standard Minecraft directory for shared game files. Reuse healthy assets, libraries, and versions directly. Keep mods, worlds, and other profile data in the selected profile.
